# 수질 예측 모델 성능 개선을 위한 결측치 처리 전략 비교 연구

🏆 품질경영학회 우수발표논문상 수상 (2024)

---

## 📌 개요

**"어떻게 처리하느냐"가 모델 성능을 결정한다는 것을 통계적으로 증명한 연구.**

결측치 처리 방식이 모델 성능에 미치는 영향을 통계적으로 검증한 연구.
단순히 모델을 구축하는 데 그치지 않고, 처리 전략 선택의 중요성을
가설 설정 → 실험 → 통계 검증으로 연결했다.

---

## 📊 데이터

- **출처:** Kaggle Water Potability Dataset
- **목표:** 수질 특성 기반 음용 가능 여부 이진 분류
- **변수:** pH, Hardness, Solids, Chloramines, Sulfate 등 9개 피처

---

## 🔬 실험 설계

- **결측치 처리 방식 4가지:** 단순 삭제 · 중앙값 대체 · KNN 대체 · 랜덤포레스트 기반 대체
- **분류 모델 5가지:** SVM · Random Forest · KNN · Logistic Regression · Decision Tree
- **총 20가지 조합** 5회 반복 측정 후 Accuracy와 ROC-AUC 지표 비교

---

## 📈 결과

- **최우수 조합:** SVM + 랜덤포레스트 기반 대체 → 정확도 67%
- 결측치 처리 방식에 따른 성능 차이 최대 20% 이상
- 2way ANOVA · Tukey HSD 사후검정으로 통계적 유의성 입증
